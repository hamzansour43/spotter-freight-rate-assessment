# Freight Rate Prediction

This project explores and predicts posted freight rates for individual loads. It compares a linear regression baseline, Random Forest, and CatBoost using a chronological holdout, then fits the selected model on all labeled data to generate validation predictions and a December forecast.

## Project contents

| Path | Description |
| --- | --- |
| `Data/train-test.csv` | Labeled development data, including the `posted_rate` target. |
| `Data/validation.csv` | Unlabeled loads for final inference. |
| `Data/december-chart-inputs.csv` | 31 December 2025 scenarios with model predictions. |
| `Notebooks/eda.ipynb` | Data exploration, feature engineering, model comparison, final fit, and validation prediction workflow. |
| `eda_findings.md` | Detailed exploration, data-quality observations, validation strategy, and model results. |
| `validation_predictions.csv` | Final validation output in the required `load_id,predicted_rate` format. |
| `src/Score.py` | Validates the prediction files and creates the December chart. |
| `scorer_results/candidate_december.png` | December prediction chart generated by the scorer. |
| `reports/freight_rate_prediction_report.pdf` | Project report, including the target distribution, feature importance, model results, and December chart. |

## Setup

Use Python 3.10 or later. From the repository root, create and activate a virtual environment, then install the project dependencies:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Open `Notebooks/eda.ipynb` in VS Code with the Python and Jupyter extensions, select the environment created above as the notebook kernel, and run the cells in order. The notebook reads the CSVs from `Data/` using paths relative to the notebook directory and writes `validation_predictions.csv` to the repository root.

## Modeling approach

The notebook builds calendar features (month, day of week, ISO week, and quarter), nonlinear distance (`distance_squared`), weight per mile, and a pickup-to-delivery lane. Categorical variables are one-hot encoded for the linear and Random Forest models; CatBoost uses native categorical handling.

Validation is chronological to mimic predicting future loads: the models train on January–August 2025 (38,477 rows) and are evaluated on September–October 2025 (9,523 rows). The separate unlabeled validation file is not used to select models. Negative weights are treated as missing in model-input copies; the source data is left unchanged. See [`eda_findings.md`](eda_findings.md) for the data-quality details and modeling assumptions.

### Chronological holdout results

Lower values are better for each metric.

| Model | MAE | RMSE | MAPE |
| --- | ---: | ---: | ---: |
| Linear Regression | $187.14 | $649.07 | 8.37% |
| Random Forest | $139.19 | $655.53 | **6.07%** |
| CatBoost | **$131.57** | **$642.17** | 6.12% |

CatBoost was selected using MAE as the primary metric and also had the lowest RMSE. Random Forest had a slightly lower MAPE. These are results from one holdout period, not a guarantee of future performance; rolling-window validation would provide a more robust estimate.

After model selection, CatBoost was refit on all 48,000 labeled rows. The notebook uses it to predict the 12,000 rows in `Data/validation.csv`. The predictions are not scored locally because that file has no target labels.

## Validate prediction files and create the December chart

From the repository root, run:

```powershell
python src/Score.py --predictions validation_predictions.csv --december-predictions Data/december-chart-inputs.csv
```

The scorer checks the 12,000 validation predictions and the 31 daily December predictions, then writes `scorer_results/candidate_december.png`. It validates output format and values; it does not train a model or calculate holdout metrics.

## Report

See [`reports/freight_rate_prediction_report.pdf`](reports/freight_rate_prediction_report.pdf) for the full analysis, model comparison, feature-importance chart, limitations, and December forecast visualization. The detailed findings are in [`eda_findings.md`](eda_findings.md).

## Notes

- The December predictions are model outputs for a fixed lane and shipment profile with the date changing by day. They should not be interpreted as observed market rates.
- Feature importance describes how the fitted model uses features; it does not establish causal effects.
- The holdout performance is based on one chronological split. Additional rolling-origin evaluation is recommended before production use.
